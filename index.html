📖 简介

债序天工 是一个面向智能体的企业级项目还债流 Skill。 它不是普通 checklist，而是一套“先查债、再排债、最后还债”的项目治理流程。

它会从安全、数据、发布、测试、架构、代码、UI、性能、观测、文档治理等维度审视项目， 并把债务整理成可执行、可验证、可排序的还债台账。

🔍 审视哪些债？

债务类型 重点检查 默认优先级
安全债 认证、授权、密钥、越权、输入校验、依赖漏洞 P0 / P1
数据债 迁移、备份、恢复、敏感数据、审计、保留策略 P0 / P1
发布债 构建、CI/CD、环境一致性、回滚、发布门禁 P0 / P1
测试债 核心链路回归、集成测试、E2E、测试稳定性 P1 / P2
架构 / 代码 / UI 债 边界、复杂度、重复逻辑、状态、响应式、可访问性 P2 / P3

📊 还债等级

等级 含义 处理方式
P0 安全事故、数据损坏、权限绕过、发布阻断、不可恢复状态 立即修，不排队
P1 核心链路失败、回滚不可靠、关键测试缺失、高频稳定性问题 近期修
P2 维护效率、扩展性、体验一致性、架构清晰度问题 纳入治理计划
P3 低风险 polish、局部整理、文档补充 低优先级排队
