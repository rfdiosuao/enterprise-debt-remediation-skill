更新日志

记录 Skill 契约、适配器、README、文档站、发行包和发布安全默认值的变化。

2026-07-06

`/hz goal` 与文档站升级

  • `hz` 新增 `goal` 子模式：先审计债务，再生成解决债务的 Codex `/goal`。
  • 核心契约和 Claude Code、OpenClaw、Hermes 适配器同步支持 `audit|plan|fix|goal`。
  • README 和中文 README 增加品牌图、Star Growth、当前 `dist` 下载入口和可复现打包脚本。
  • 文档站首页改为正式项目页，首屏展示 logo、四个子模式、Star 增长和安装路径。
  • `luming-preview` 在公网绑定时要求显式设置 `LOOM_ADMIN_PASSWORD`，避免默认后台密码进入公开环境。

2026-05-20

Wiki 改成文档型首页

  • 首页改成文档型 Wiki 结构，包含定位、快速开始、表格和参考入口。
  • 新增独立更新日志页，方便后续记录 Skill 变化。
  • 保留 GitHub Pages 静态发布方式，不引入额外构建流程。

2026-05-20

新增 Windows UTF-8 预检

  • 核心契约加入“先识别系统，再决定编码”的运行前置。
  • 新增 `bootstrap_windows_utf8.ps1`，用于 Windows 会话级 UTF-8 初始化。
  • 同步重打 `.skill` 发行包。

2026-05-20

首个公开版本

  • 发布 `enterprise-debt-remediation` 完整 Skill。
  • 发布 `hz` 极简入口，支持 `/hz audit`、`/hz plan`、`/hz fix`。
  • 补齐 Codex、Claude Code、OpenClaw、Hermes 适配说明。
